# 智能薪酬考勤系统 · Payroll Calculator HR

把考勤机导出的 Excel 拖进浏览器，自动算出每个人的**迟到、早退、缺卡次数和扣款金额**，一键导出月度核算表。

纯前端实现，不连服务器、不传数据、不需要安装。

## 为什么用它

| 痛点 | 这个工具的做法 |
| --- | --- |
| 手动算迟到早退，几十号人算到眼花 | 上传表格，秒级出结果 |
| HR 数据敏感，不敢传第三方网站 | 全部在浏览器本地计算，断网也能跑 |
| 考勤机导出的表头五花八门 | 自动识别中英文列名，顶部带标题行也能找到表头 |
| 周末加班打卡被误判成迟到 | 周末默认整行跳过，可手动开启参与核算 |
| 算完还要手写汇总表 | 一键导出 Excel，附「核算参数」便于复核存档 |

## 快速开始

**方式一：直接打开（推荐）**

下载仓库后双击 `index.html`，用 Chrome / Edge / Safari 打开即可。

页面会从 CDN 加载 SheetJS 解析库。若使用环境不能连外网（公司内网、断网），把 `xlsx.full.min.js` 下载后放进 `assets/vendor/` 目录，页面加载失败时会自动回退到本地文件，实现完全离线运行：

```bash
mkdir -p assets/vendor && curl -o assets/vendor/xlsx.full.min.js \
  https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js
```

**方式二：本地起个服务**

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

然后访问 `http://localhost:8000`。

**四步完成核算**

1. **设参数** —— 扣款系数（元/分钟）、上班时间（默认 08:00）、下班时间（默认 17:00）。参数自动存本地，下次打开还在。
2. **传表格** —— 点击上传区或把 `.xlsx / .xls / .csv` 拖进去。
3. **看结果** —— 顶部看板显示人数、缺卡人次、迟到早退合计、预计扣款；下方是逐人明细。
4. **导 Excel** —— 点「导出 Excel」得到月度核算表，或点「打印」直接出纸质版。

### 表结构

一行 = 一名员工的一天。同一员工的多天数据写多行，工具按工号自动合并汇总。

| 列名 | 中文名 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Person ID` | 工号 | ✅ | 员工唯一编号。纯数字工号建议把单元格设为「文本」，否则 Excel 会显示成 `1.001E+03` |
| `Name` | 姓名 | ✅ | 同一工号在各行保持一致 |
| `Date` | 日期 | ✅ | 推荐 `YYYY-MM-DD`（如 `2026-09-01`），也兼容 `2026/9/1` 与 Excel 日期格式 |
| `Check-In` | 上班打卡 | ⬜ | 当天首次打卡，`HH:mm` 或 `HH:mm:ss`；未打卡填 `-` |
| `Check-out` | 下班打卡 | ⬜ | 当天末次打卡；未打卡填 `-` |

> 表头不必完全一致：只要包含「工号 / 姓名 / 日期 / 上班 / 下班」这类关键字就能识别，中英文皆可。表头也不一定在第 1 行，程序会在前 20 行里自动定位（考勤机导出的表格常带标题行）。

## 核算规则

设：

- `S` = 上班基准时间（默认 08:00）
- `E` = 下班基准时间（默认 17:00）
- `k` = 扣款系数（默认 1 元/分钟）

| 项目 | 判定与计算 |
| --- | --- |
| **有效出勤天数** | 每条有效记录记 1 天 |
| **迟到分钟** | `Check-In > S` 时，`⌈(Check-In − S) ÷ 60⌉`（分钟向上取整，8:00:01 记 1 分钟） |
| **早退分钟** | `Check-out < E` 时，`⌈(E − Check-out) ÷ 60⌉`；晚于 E 下班**不抵扣** |
| **缺卡次数** | 上班或下班任一侧为 `-` / 空，记 1 次；缺卡天数仍计入有效天数 |
| **扣款** | `(迟到分钟 + 早退分钟) × k` |
| **周末** | 周六周日默认整行跳过（双休或加班），不计天数、不判迟到早退；勾选「周末打卡也参与核算」后按工作日规则计算 |

被跳过的行会在结果区标注：`已跳过 N 条周末记录`、`已忽略 N 行无效数据`。

### 几个刻意的设计

- **早到不加分、晚走不抵扣。** 迟到和早退分开累计，避免「早上迟到 10 分钟、晚上多待 30 分钟」相互抵消后算不出问题。
- **缺卡只计数、不单独罚钱。** 缺卡常是忘打卡，具体罚款口径各家不同，这里只给次数供 HR 判断；如需「每次缺卡扣 X 元」，可在导出的 Excel 里加一列公式。
- **分钟向上取整。** 8:00:01 到岗记 1 分钟，避免秒级误差被算成 0。

## 导出结果

点击「导出 Excel」生成 `HR考勤薪酬核算表_YYYYMMDD.xlsx`，含两个工作表：

**Sheet 1 · 月度核算明细**

| 序号 | 工号 | 员工姓名 | 有效出勤天数 | 异常缺卡次数 | 迟到分钟合计 | 早退分钟合计 | 迟到早退合计(分) | 扣款系数(元/分) | 应扣款金额(元) |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

已按工号排序，可直接作为薪酬表的一列数据源。

**Sheet 2 · 核算参数**

记录本次核算的数据来源文件名、参与人数、有效人天、缺卡人次、迟到早退合计、扣款系数、上下班基准、周末规则、跳过行数、生成时间——用于复核与留痕。

## 常见问题

**Q：表格传上去提示「表头无法识别」？**
检查这五列是否齐全，且关键字能被识别：工号（Person ID / 工号 / 员工编号）、姓名（Name / 姓名）、日期（Date / 日期）、上班（Check-In / 上班打卡 / 签到）、下班（Check-out / 下班打卡 / 签退）。建议先下载空白模板对照表头。

**Q：工号显示成 `1.001E+03`？**
Excel 把工号当数字了。选中该列 → 设置单元格格式 → 文本，再重新输入；或在数字前加英文单引号。

**Q：时间列显示成 `0.335` 这种小数？**
那是 Excel 的时间序列值。单元格格式改成「时间」即可正常显示；程序读取的是原始值，两种显示都不影响核算。

**Q：日期是 `2026/9/1` 或 `9/1/2026` 能认吗？**
能。`YYYY-MM-DD`、`YYYY/M/D`、`M/D/YYYY`、Excel 日期格式、日期序列值（如 `46266`）都会自动转换，不受系统区域设置影响。

**Q：一天有多次打卡怎么办？**
工具按「一行一天」处理，取该行的值作为当天上班/下班时间。中控、海康、钉钉等考勤机的日报表通常已汇总好首次/末次打卡，直接导出即可。

**Q：文件有多个工作表，读哪个？**
自动扫描所有工作表，选表头匹配最完整的那个，不怕前面有封面页、说明页。

**Q：支持 CSV 吗？中文会不会乱码？**
支持。CSV 建议用 UTF-8 编码保存，Excel 另存的 CSV 在 Windows 下是 GBK，可能出现中文乱码，这种情况建议直接上传 `.xlsx`。

**Q：数据会被上传吗？**
不会。所有解析和计算都在你的浏览器里完成，关掉页面即清空。唯一的网络请求是加载 CDN 上的 SheetJS 解析库（不含任何业务数据）；按上面的方法把库放到本地后，连这个请求也没有。

**Q：能用手机/平板打开吗？**
可以，页面做了响应式适配，但上传操作在电脑上更方便。
